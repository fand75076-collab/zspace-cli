# 应用覆盖与验收

v0.5.1 包含 291 个操作、40 个功能域和 318 条 CLI 命令。MCP 默认提供 42 个查询/本机工具，显式启用写入后 57 个工具。工具按域聚合，不与应用数一一对应。

以下表格描述源代码中的应用支持范围，不是任何设备的已安装应用清单。某个应用的全部内部功能不一定已接入。完整参数见 [operations.json](operations.json)；需要查询自己 NAS 的实时安装情况时，可在授权连接下使用 `zspace apps coverage --json`。

## v0.5 新增工作流

38 个新增操作分布在记事本（3）、相册（8）、音乐（15）、有声读物（7）、影视（5）；同时为原有笔记列表增加颜色和排序筛选。五组实机流程覆盖分类/标签、音乐导入/歌词/CUE/四类收藏、有声书目录/章节、相册索引/成员和影视合集/收藏，14 项清理检查全部通过。仅使用生成的媒体和 UUID 命名测试对象，源文件移入回收站。

详情与范围见 [应用契约](application-contracts-v0.5.md) 和 [脱敏报告](acceptance-app-workflows-v0.5.json)。新增命令的 `validation` 元数据是发布时的协议版本和脱敏验收记录，不会实时检测另一台 NAS 的兼容性。没有元数据的历史命令沿用原有分项证据，不能推断为未测试或全部测试。

## 实测依据

- v0.5.1 离线测试：125 项 Node 测试通过；新增公开文件隐私检查及其回归测试，原有功能实现保持兼容。

- v0.5.0 离线测试：123 项 Node 测试；新增 38 个操作逐项检查真实 HTTP 编码、实际 CLI 和 MCP 子进程、参数拒绝、写入确认、Agent 授权及撤销。五组 NAS 实机流程全部通过。

- v0.4.0 离线自动测试：78 项 Node 测试（其中一项运行 10 项 Python 桥接测试），包括官方 MCP client 的真实 stdio 子进程、写入开关、参数限制、会话重读和输出遮盖。
- v0.2.0 NAS MCP 实机验收：161 项通过，0 项测试失败；HDMI 的两个不可用接口单列限制。5 组测试数据均已清理。包含 156 个查询检查，以及笔记/分类/歌单/相册/有声书库 5 组 CRUD 检查。
- v0.2.0 文件 CLI 实机验收：30 项通过，包括 Unicode、2 MiB 二进制、空文件、JSON、分页、复制/移动和 SHA-256 比对；测试目录确认进入回收站。
- v0.4.0 Agent MCP 实机验收：20 项通过，0 项失败；两个独立客户端、权限发现/撤销、私密来源验证、合成文件哈希和笔记 CRUD，见 [Agent 报告](acceptance-agent-v0.4.json)。
- v0.3.0 Android MCP 实机验收：23 项通过，0 项失败，stdout/stderr 协议检查通过。包括四个专属应用入口、可见界面、书库页切换、中文输入及取消、滚动、返回、写入开关和失效 target；见 [安卓报告](acceptance-android-v0.3.json)。未创建分类或备份任务，未更改亲情账号。NAS 认证/系统/存储 doctor 回归通过。
- 验收没有使用现有容器、虚拟机和存储设置进行破坏性测试。启停、删除、安装等接口的发布依据是网页调用契约和离线请求测试，不能称作全部写命令已实测。

## 已知限制

- v0.5 自定义影视合集需要普通库；不刮削库返回 `N120039`。有声书前端遗留的 CUE 解析端点本次返回 `HTTP_ERROR`，未作为命令发布；音乐 CUE 读取已实测。外部存储状态只验证了内置盘书库，没有拔插真实外置设备。
- HDMI 接口的历史验收记录有 HTTP 502；接口可用性需要在目标环境重新确认。
- 未完成独立授权的网盘返回 N0010002/N0010005；CLI 保留 NAS 原始业务错误码。Dropbox 当前只接入授权状态，中国移动网盘没有同步计划接口。
- 迅雷、花生壳目前只读取绑定/服务状态，不提取或输出其独立设备密钥。节点小宝、云端客服/论坛/帮助只有目录或应用管理。
- 极阅读、极漫画、亲情设置和手机备份以 `android-ui` 接入，要求已连接、解锁、登录正确 NAS 的手机。可见界面桥接不能替代完整书库分页和独立业务 API；未验证每个界面中的所有功能。Mac 已登录不会自动赋予手机业务 API。备份到 NAS 的普通文件可由 files 管理。
- 影像处理、本地 AI、Office 等只提供列出的状态/查询能力；不包含全部转换、推理或编辑功能。
- 没有 NAS 格式化、删除存储池、清空文件回收站的专用 API 命令，也不实现密码/MFA 绕过。Android 通用点击能触发界面上提供的操作，调用方需按具体用户授权执行。
