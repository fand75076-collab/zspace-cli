# 公开内容与隐私

公开仓库只包含通用代码、示例、接口契约和脱敏测试记录。账号与连接配置由使用者在本机创建，不附带预置设备或登录状态。

- 示例使用保留域名、占位路径和合成测试值。
- 公开验收报告移除设备身份、私人联系方式、已安装应用清单、精确运行时间和测试运行标识；保留功能测试项、协议版本及结果。
- 本机原始报告、截图、HAR、会话、配置和研究文件不应提交；它们可能包含私有数据。请保存在忽略目录，分享前另行脱敏。
- 提交者应在 Git 配置中使用自己的 GitHub noreply 邮箱。不要把私人邮箱写入公开提交元数据。
- `npm run privacy-check` 检查常见私人路径、内网地址、设备域名、个人邮箱、令牌形态以及报告中的环境字段；CI 会执行同样检查。它不能替代提交前人工检查。

运行 CLI/MCP 时，NAS 返回的文件名、笔记、媒体和应用状态仍可能是私人内容。公开仓库的脱敏不意味着运行结果可以直接分享。凭证处理与访问边界见 [SECURITY.md](../SECURITY.md)。
